Sobre o Projeto

O EcoSense e um sistema distribuido de monitoramento ambiental que utiliza microcontroladores ESP32 com sensores de particulas (PM2.5, PM10), CO2, temperatura e umidade. Os dados sao transmitidos via MQTT para um broker Mosquitto e processados por um pipeline Python que aplica modelos de classificacao (Random Forest + LSTM) para predicao de qualidade do ar.
